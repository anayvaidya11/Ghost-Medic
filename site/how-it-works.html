How it works

Four parts, one line of text between them.

Sensing on the wrist, thinking on the device you carry, one line of plain text between them ten times a second. Every stand-in is flagged.

The wrist unit

Three sensors, and one thing it refuses to report

Three sensors, each answering a different question, driven by C that runs straight on the chip.

The partWhat it measuresWhat that is good for
BMP280Air pressure and temperatureAir thins predictably as you climb, so pressure gives you altitude. The temperature is the air around the device, not your body.
LIS3DHAcceleration, three directionsMotion, and the particular signature of a fall.
MAX30102Light reflected off skinRaw light readings, and deliberately nothing more. See below.

Height from air pressure

Run the pressure reading backwards to get height:

float bmp280_pressure_to_altitude(float pressure_pa) {
    return 44330.0f *
        (1.0f - powf(pressure_pa / BMP280_SEA_LEVEL_PA, 0.1903f));
}

The catch, which is in the code too: the sea-level reference never changes, but real air pressure does. Good for telling you that you climbed 300 m. Not for how high you are. Not GPS.

What a fall looks like to a machine

Falling reads near zero, landing spikes. Either one on its own happens all day, so the wrist unit only calls it a fall when both happen, in that order, within 400 ms.

Label

A demonstration, not a medical-grade detector. The levels it triggers at are textbook numbers nobody has tuned, and the code says so.

No heart rate

A pulse is buried in the light readings. Extracting it is work this project does not do, and four things hold that line:

  • the wrist unit only ever reports how much light came back;
  • the app has nowhere to put a heart rate;
  • the text sent to the model forbids working one out;
  • a test fails if one ever shows up.

A made-up vital sign is worse than none.

The link

A cable doing a radio's job

A short-range radio would carry this. Until one exists, a small program passes each line along a wire unchanged; nothing further along can tell a real board from a replayed recording. It drops one thing only: the power-on greeting, which carries no reading.

The screen

Six steps, and one line that matters more than the rest

Six steps at most, one sentence each, and a separate line telling you whether to get out. Worked-out readings stay apart from raw ones; anything that failed shows a dash.
